# C++ 开发环境

编译器将源文件翻译为目标文件，链接器把目标文件和库合成可执行程序。CMake 读取项目配置并生成构建规则。Git 管理源码版本。

Windows 可安装 Visual Studio Build Tools 的「使用 C++ 的桌面开发」工作负载，并确保 CMake 支持所装的 Visual Studio 版本。Linux 可安装 GCC 或 Clang。编辑器可以使用 VS Code。

```bash
git --version
cmake --version
```

在仓库根目录运行 [构建命令](../../README.md#c-示例)，或进入 [Hello World](../hello/) 单独练习。
