# 对象生命周期与智能指针

局部对象离开作用域时自动析构。`std::unique_ptr` 表示独占所有权，通常用 `std::make_unique` 创建。通过 `std::move` 可以转移所有权。下面的对象在 `owner` 离开作用域时析构。

```cpp
#include <iostream>
#include <memory>

class Entity {
public:
    Entity() { std::cout << "Created Entity!\n"; }
    ~Entity() { std::cout << "Destroyed Entity!\n"; }
};

int main() {
    auto owner = std::make_unique<Entity>();
}
```

`std::shared_ptr` 支持多个所有者。最后一个所有者释放后对象析构。`std::weak_ptr` 可以观察对象并打破循环引用。一般优先把对象放在局部作用域，需要动态分配时再按所有权选择智能指针。
